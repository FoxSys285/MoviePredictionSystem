# Báo cáo

Mỗi thành viên viết phần mình phụ trách và xác nhận bảng số liệu trước khi TV5 ghép báo cáo cuối:

- TV1: dữ liệu, EDA, chia tập, baseline và cold-start.
- TV2: Linear/XGBoost, classification và kết quả.
- TV3: SVD/KNN, giảm chiều, phân cụm và kết quả.
- TV4: NCF, Optuna, learning curve và kết quả.
- TV5: Apriori, web demo, bảng tổng hợp và kết luận chọn mô hình.

Nội dung chi tiết xem [hướng dẫn công việc](../docs/HUONG_DAN_CONG_VIEC_TUNG_THANH_VIEN.md). Phần TV1 hiện nằm ở [tv1_data.md](tv1_data.md).

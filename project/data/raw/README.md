# Dữ liệu gốc

MovieLens 25M đã có ở `../../../Dataset/ml-25m` tính từ thư mục này. Đường dẫn từ gốc `project` được khai báo trong `configs/default.json` là `../Dataset/ml-25m`.

Không sao chép các CSV lớn vào đây. Nếu nhóm chạy trên máy khác, tải dữ liệu từ [GroupLens](https://grouplens.org/datasets/movielens/25m/) rồi cập nhật `dataset_dir` trong cấu hình. Kiểm tra README và điều kiện sử dụng đi kèm bộ dữ liệu.
